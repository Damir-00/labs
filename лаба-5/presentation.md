# 1. Менеджер паролей pass

`pass` — это менеджер паролей для Linux.

Основные возможности:

- хранение паролей в файловой системе;
- шифрование через GPG;
- создание и генерация паролей;
- интеграция с Git.

---

# 2. Проверка GPG

Перед началом работы необходимо проверить наличие GPG-ключа.

Команда:

```bash
gpg --list-secret-keys
```

GPG используется для шифрования базы паролей.

# 3. Установка pass

Установка программы:

```bash
sudo dnf install pass pass-otp
```

После установки создается возможность работать
с защищенным хранилищем паролей.

---

![width:700px](скрины/2.png)

---

# 4. Инициализация pass

Подключение GPG-ключа:

```bash
pass init <email>
```

После выполнения:

```
Password store initialized
```
---

![width:700px](скрины/4.png)

---

# 5. Работа с паролями

Создание записи:

```bash
pass insert github/test
```

Просмотр:

```bash
pass github/test
```

Генерация нового пароля:

```bash
pass generate --in-place github/test
```

# 6. Использование Git в pass

Для хранения истории изменений:

```bash
pass git init
```

Проверка:

```bash
pass git status
```

Git позволяет контролировать изменения
в хранилище паролей.

# 7. Что такое chezmoi?

`chezmoi` — инструмент для управления
конфигурационными файлами пользователя.

Позволяет:

- хранить настройки в Git;
- переносить конфигурацию между системами;
- применять изменения автоматически.

---

# 8. Установка chezmoi

Установка:

```bash
sh -c "$(wget -qO- chezmoi.io/get)"
```

После установки программа доступна
из командной строки.

![width:700px](скрины/9.png)

---

# 9. Репозиторий dotfiles

Создается отдельный репозиторий
для хранения настроек Linux.

Пример:

```
dotfiles
 ├── .bashrc
 ├── настройки терминала
 └── конфигурационные файлы
```
---
![width:700px](скрины/12.png)

---

# 10. Проверка изменений

Перед применением настроек:

```bash
chezmoi diff
```

Команда показывает,
какие файлы будут изменены.


---
![width:700px](скрины/12.png)

---

# 11. Применение конфигурации

Применение изменений:

```bash
chezmoi apply -v
```

После выполнения конфигурация
копируется в домашний каталог.
