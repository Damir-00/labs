# 3. Теоретические сведения

## 3.1. Командная оболочка UNIX

Командная оболочка UNIX предоставляет пользователю интерфейс для взаимодействия с операционной системой.

С помощью командной оболочки можно:

* запускать программы;
* работать с файлами и каталогами;
* передавать аргументы программам;
* перенаправлять ввод и вывод;
* создавать командные файлы;
* использовать условные конструкции;
* использовать циклы;
* автоматизировать выполнение операций.

В лабораторной работе используется командная оболочка **Bash**.

---

## 3.2. Командные файлы Bash

Командный файл представляет собой текстовый файл, содержащий последовательность команд оболочки.

Обычно Bash-скрипт начинается со строки:

```bash
#!/bin/bash
```

Данная строка определяет интерпретатор, который используется для выполнения командного файла.

Для предоставления файлу прав на выполнение используется команда:

```bash
chmod +x имя_файла.sh
```

После этого файл можно запустить следующим образом:

```bash
./имя_файла.sh
```

Также командный файл можно запустить непосредственно через интерпретатор:

```bash
bash имя_файла.sh
```

---

## 3.3. Условные конструкции

В Bash условные конструкции позволяют проверить определённое условие и выполнить соответствующие команды.

Пример:

```bash
if [ условие ]
then
    команды
else
    команды
fi
```

Условные конструкции используются в лабораторной работе, например, при проверке существования файла справки.

---

## 3.4. Циклы

Циклы позволяют многократно выполнять определённый набор команд.

Пример цикла `while`:

```bash
while [ условие ]
do
    команды
done
```

Пример арифметического цикла `for`:

```bash
for ((i=1; i<=10; i++))
do
    echo "$i"
done
```

Циклы используются в заданиях лабораторной работы для ожидания освобождения ресурса и генерации последовательности символов.

---

## 3.5. Переменная `$RANDOM`

В Bash существует встроенная переменная `$RANDOM`, предназначенная для получения псевдослучайных чисел.

Согласно методическим указаниям, значение `$RANDOM` находится в диапазоне от `0` до `32767`.

Пример использования:

```bash
echo $RANDOM
```

Полученное значение можно использовать для выбора случайного символа латинского алфавита.

---

## 3.6. Семафор

Семафор используется для организации доступа нескольких процессов к общему ресурсу.

В рамках данной лабораторной работы реализуется упрощённый механизм семафора.

Процесс должен:

1. ожидать освобождения ресурса;
2. сообщать пользователю о том, что ресурс занят;
3. после освобождения получить ресурс;
4. использовать ресурс определённое время;
5. освободить ресурс для следующего процесса.

Методическое задание также предусматривает доработку программы для взаимодействия трёх и более процессов.

---

## 3.7. Справочная система `man`

В операционных системах UNIX/Linux команда `man` используется для получения справочной информации о командах и программах.

В данной лабораторной работе необходимо создать собственный командный файл, который получает имя команды в качестве аргумента и ищет соответствующий файл справки в каталоге:

```text
/usr/share/man/man1
```

Если справочный файл существует, его содержимое должно быть выведено пользователю.

Если соответствующий файл отсутствует, программа должна вывести сообщение об отсутствии справки.
