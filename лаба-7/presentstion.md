# Работа с правами доступа

Изучена команда `chmod`.

Получены навыки изменения прав доступа к файлам и каталогам.

Используемые режимы:

- `744`
- `711`
- `544`
- `664`

### Пример

```bash
chmod 744 australia
chmod 711 play
chmod 544 my_os
chmod 664 feathers
```
