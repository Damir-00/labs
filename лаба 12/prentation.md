# Задание №1

## Резервная копия командного файла

Создан файл:

```text
backup.sh
```

Для создания резервной копии используется архиватор `tar`.

Основные команды:

```bash
chmod +x backup.sh
./backup.sh
ls -lh backup
```

---

![](lab-12/3.png)

---

# Создание резервной копии

Скрипт создаёт архив:

```text
backup/backup.sh_backup.tar.gz
```

Архив создаётся командой:

```bash
tar -czf "$BACKUP_DIR/${SCRIPT_NAME}_backup.tar.gz" "$0"
```

Проверка содержимого:

```bash
tar -tzf backup/backup.sh_backup.tar.gz
```

# Проверка архива

Содержимое созданного архива:

```text
./backup.sh
```

Это подтверждает успешное создание резервной копии командного файла.

## Обработка аргументов

Создан файл:

```text
args.sh
```

Скрипт определяет количество переданных аргументов:

```bash
echo "Количество аргументов: $#"
```

Все аргументы обрабатываются с помощью:

```bash
for argument in "$@"
```

# Задание №3

## Аналог команды `ls`

Создан командный файл:

```text
myls.sh
```

Скрипт:

* получает каталог в качестве аргумента;
* проверяет существование каталога;
* перебирает его содержимое;
* определяет тип объекта;
* определяет права доступа.

Команды `ls` и `dir` в скрипте не используются.

---

# Проверка `myls.sh`

Запуск:

```bash
chmod +x myls.sh
./myls.sh .
```

Программа выводит:

```text
имя объекта
тип объекта
права доступа
```
