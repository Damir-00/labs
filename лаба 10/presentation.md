# Теоретические сведения

Редактор **vi** — стандартный текстовый редактор Unix/Linux.

Он позволяет:

- создавать файлы;
- изменять существующие документы;
- искать текст;
- копировать и удалять строки;
- быстро перемещаться по файлу.

---

# Режимы работы vi

Редактор имеет три режима:

1. Командный режим.
2. Режим вставки.
3. Режим последней строки.

---
![](lab-10/1.png)

---

# Командный режим

Используется для выполнения команд:

- перемещение по файлу;
- удаление строк;
- копирование;
- поиск;
- сохранение;
- переход между строками.

Возврат в командный режим:

```text
Esc
```

---

# Режим вставки

Переход:

```text
i
```

Дополнительные команды:

```text
a
o
O
```

Выход:

```text
Esc
```

---

# Режим последней строки

После нажатия

```text
:
```

становятся доступны команды:

```text
:w
:q
:wq
:q!
:set nu
```

---

# Основные команды vi

| Команда | Назначение |
|---------|------------|
| `i` | режим вставки |
| `Esc` | командный режим |
| `dd` | удалить строку |
| `yy` | копировать строку |
| `p` | вставить |
| `u` | отменить действие |
| `G` | конец файла |
| `0` | начало строки |
| `$` | конец строки |
