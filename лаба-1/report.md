# Теоретические сведения

Fedora Linux является современным дистрибутивом операционной системы GNU/Linux, распространяемым с открытым исходным кодом.

Основными преимуществами Fedora являются:

- свободное распространение;
- высокая безопасность;
- поддержка современных технологий;
- регулярные обновления;
- большое количество программного обеспечения.

В системе используется пакетный менеджер **DNF**, предназначенный для установки, удаления, обновления и поиска программ.

Для работы администратора широко используется терминал Linux.

Основные команды позволяют получать информацию о системе, пользователях, памяти, процессоре, файловой системе и сетевых параметрах.

# Контрольные вопросы

## 1. Что представляет собой Fedora Linux?

Fedora Linux — современный свободно распространяемый дистрибутив операционной системы GNU/Linux, поддерживаемый сообществом Fedora Project при участии компании Red Hat. Дистрибутив ориентирован на использование современных технологий, регулярные обновления и высокую стабильность.

---

## 2. Для чего используется пакетный менеджер DNF?

DNF предназначен для установки, удаления, обновления и поиска программного обеспечения в официальных репозиториях Fedora. Кроме того, он автоматически разрешает зависимости между пакетами.

---

## 3. Для чего используется команда `hostnamectl`?

Команда `hostnamectl` применяется для просмотра и изменения имени компьютера, а также отображения общей информации о системе.

---

## 4. Для чего применяется команда `uname`?

Команда `uname` предназначена для получения информации об операционной системе и ядре Linux. Наиболее часто используются параметры:

- `uname -r` — версия ядра;
- `uname -a` — полная информация о системе.

---

## 5. Для чего используется команда `localectl`?

Команда `localectl` применяется для просмотра и настройки локализации системы, языка интерфейса и раскладки клавиатуры.

---

## 6. Что представляет собой X11?

X11 (X Window System) — оконная система, обеспечивающая работу графического интерфейса пользователя в операционных системах семейства UNIX и Linux.

---

## 7. Для чего используется SELinux?

SELinux (Security-Enhanced Linux) — механизм разграничения доступа, повышающий безопасность операционной системы за счёт применения политик контроля доступа.

---

## 8. Почему рекомендуется регулярно обновлять систему?

Регулярное обновление позволяет устранять обнаруженные ошибки, закрывать уязвимости безопасности, получать новые версии программного обеспечения и поддерживать стабильную работу операционной системы.

```bash
sudo hostnamectl set-hostname fedora
hostnamectl
whoami
uname -r
uname -a
cat /etc/fedora-release
```

```bash
mkdir ~/lab1
ls -l ~
```

## Настройка Sway

```bash
mkdir -p ~/.config/sway
nano ~/.config/sway/config
cat ~/.config/sway/config
```

## Настройка X11

```bash
cd /etc/X11
ls -la
cat /etc/X11/xorg.conf.d/*.conf
```

```bash
localectl status
sudo localectl set-locale LANG=ru_RU.UTF-8
sudo localectl set-keymap us,ru
```

getenforce
sestatus
